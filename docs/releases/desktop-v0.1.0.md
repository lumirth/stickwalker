This is the first release of Stickwalker Desktop for macOS, Windows, and Linux. Plug in your StickS3 over USB to install or update the firmware, edit its six palettes, or move a save between the Stick and an emulator. When you update from an earlier public Stickwalker candidate, Desktop carries over your save and settings. Download the disk image for Apple silicon, the Windows executable, or the Linux archive below.
