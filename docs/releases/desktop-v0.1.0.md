This is the first release of Stickwalker Desktop for macOS, Windows, and Linux.

You can plug in your StickS3 using a data-capable USB-C cable to install/update firmware, edit the Stickwalker's six palette slots, or move a save between your Stick and an emulator.

Luckily, if you're on a version that was made before the desktop app, it should carry over your save and settings when you update from an earlier version. Download the macOS disk image (Apple silicon only), Windows executable, or Linux archive below.
