This is the first stable Stickwalker firmware for the M5Stack StickS3. It improves infrared communication with HeartGold, SoulSilver, and other walkers, and keeps the last completed save if a write loses power. The Stick sleeps between batches of steps while you walk with the screen off. Install or update with [Stickwalker Desktop](https://github.com/lumirth/stickwalker/releases/latest) to keep your existing save and settings.
