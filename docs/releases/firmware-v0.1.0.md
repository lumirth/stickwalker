This is the first stable Stickwalker firmware for the M5Stack StickS3. It improves infrared communication with HeartGold, SoulSilver, and other walkers. It protects your last save if the battery runs out or power is interrupted. The Stick sleeps between batches of steps while you walk with the screen off. To keep your save and settings, install the update with [Stickwalker Desktop](https://github.com/lumirth/stickwalker/releases/latest).
