# Preserve native motion ownership gaps

The original firmware suspends motion sampling while sound playback or IR owns the foreground and shared workspace, although ordinary menus and games continue sampling. Preserve those gaps because the user prefers the original behavior as part of fidelity. Process each eligible sample immediately on the existing inactive/activity and moving/interactive schedules. Do not introduce deferred FIFO motion batching; the user declined it unless the original firmware did it. The native FFT window remains unchanged. See [screen-off wake policy](0002-m-only-dark-wake.md).
