# Recover over USB

1. Connect the StickS3 to your computer with a USB data cable. Open Stickwalker Desktop, select your Stick, and choose **Install Stickwalker**. If that option doesn't appear, hold Power until the green light blinks (about four seconds), then release and try again. A reinstall keeps your Stickwalker save. **Erase and Install** clears it.
2. If holding Power doesn't make the light blink and Desktop still can't start the installation, use M5Stack's PM1 updater to restart the power controller. Then return to Desktop and install Stickwalker.
